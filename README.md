# star-charter-pro

game · constellation charting (pro)

The "Pro" edition of Star Charter — trace constellations against the clock with
procedural audio, particle FX, a title/attract screen, and a persistent local
leaderboard. Scored on speed and accuracy.

**No build tools. No frameworks.** Open `index.html`.

## What it is
A single-file canvas game built on a requestAnimationFrame loop with generated
WebAudio. Local high scores via `localStorage`; touch + keyboard; reduced-motion
aware. The full design lives in `docs/DESIGN.md` (the original 230-line design doc).

## Run
```
start index.html
```

Shipped. See `docs/DESIGN.md` for the complete design.
